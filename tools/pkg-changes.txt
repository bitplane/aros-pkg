INSTALL accepts AT with an existing absolute destination directory outside the selected root for one application drawer. The selected root remembers the placement; shared dependencies use their own normal locations.
UPGRADE, VERIFY, REPAIR, ROLLBACK and REMOVE follow the recorded placement. Commands report the destination, and unavailable volumes or incompatible application layouts produce explicit refusals.
Relocated applications retain their signed manifests. File placement uses staging on the destination volume, and conflicting destinations and redirected paths are refused.
