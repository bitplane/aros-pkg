On Windows, a package holding a file whose name is not plain ASCII, such as Catalogs/français/AiRcOS.catalog, was refused with "cannot stage ... No such file or directory": the file was opened under the machine's code page instead of its real name. Fixed, and the same for a cache or a user folder whose name holds such a character or a space.
PUBLISH and MANIFEST take INFO <file>: a .pkginfo file a port carries, saying what the package is (name, version, kind, the catalogue fields, its dependencies and which installed files belong to it), so that packaging it needs no hand-written table.
