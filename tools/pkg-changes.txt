The first version on this portal, published by JKN with its own key.
RESOLVE <library> or <program> says which copy of a library AROS will open and why, checking its CPU, resident tag, type and version, and what to do when it is the wrong one.
Packages list the libraries and devices they ship (Provides), and PUBLISH warns about a library a program opens that no dependency provides.
Manifest keys Pkg does not know are ignored and named by SHOW instead of refused, so packages can carry lines for other systems.
On AROS, a file written to a volume's root, such as MOUNTLIST OUT RAM:GURU0, is no longer refused.
