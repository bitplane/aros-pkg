Pkg on AROS reads channels over the network: CHANNEL http://aros-pkg.azurewebsites.net/pkg works for INSTALL, STATUS, UPGRADE and SHOW once the network is started (AROSTCP, or a hosted AROS's own sockets). https is refused with the reason: AROS has no TLS, and Pkg checks every signature and file itself whatever the connection.
Downloads are kept in SYS:.pkg/cache on AROS, so a reboot does not fetch them again.
Install-Pkg names the network channel for later upgrades.
