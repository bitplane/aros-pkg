# The AROS system of a pc-x86_64 boot ISO, as packages.
# name | kind | paths (FILES) | configuration files (CONFIG), or -
# Left out, the ISO's own: AROS.boot boot.catalog efi.img mach_kernel .disk System/Library (a Mac boot label);
# .backdrop, Workbench desktop state, is left to the person (no drawer walk takes dot files).

aros-prefs  | application | Prefs,Prefs.info                                    | Prefs/Env-Archive
aros-fonts  | font        | Fonts,Fonts.info                                    | -
aros-locale | catalog     | Locale,Locale.info                                  | -
aros-tools  | application | Tools,Utilities,Tools.info,Utilities.info           | -
aros-demos  | data        | Demos,Demos.info                                    | -
aros-extras | application | Extras                                              | -
aros-sdk    | sdk         | Developer,Developer.info                            | -
